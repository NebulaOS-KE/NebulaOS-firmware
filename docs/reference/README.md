# The developer reference moved to this repository's wiki

The generated developer reference that used to live in this directory is now the
**[NebulaOS-firmware wiki](https://github.com/NebulaOS-KE/NebulaOS-firmware/wiki)**, kept as
Markdown pages in the repository's top-level [`wiki/`](../../wiki) directory and published from
there. One copy, one place to read it.

| Was | Now |
|---|---|
| `docs/reference/ARCHITECTURE.md` | [Architecture](https://github.com/NebulaOS-KE/NebulaOS-firmware/wiki/Architecture), [Image install and the trial](https://github.com/NebulaOS-KE/NebulaOS-firmware/wiki/Image-Install-And-Trial), [Recovery](https://github.com/NebulaOS-KE/NebulaOS-firmware/wiki/Recovery), [The black box](https://github.com/NebulaOS-KE/NebulaOS-firmware/wiki/Black-Box), [Printer configuration](https://github.com/NebulaOS-KE/NebulaOS-firmware/wiki/Printer-Configuration) |
| `docs/reference/MOONRAKER-API.md` | [Moonraker API](https://github.com/NebulaOS-KE/NebulaOS-firmware/wiki/Moonraker-API) |
| `docs/reference/OSCONFIG.md` | [OSConfig helpers](https://github.com/NebulaOS-KE/NebulaOS-firmware/wiki/OSConfig-Helpers) |
| `docs/reference/BOOT-SERVICES.md` | [Boot services](https://github.com/NebulaOS-KE/NebulaOS-firmware/wiki/Boot-Services) |
| `docs/reference/RUNTIME-HELPERS.md` | [Runtime helpers](https://github.com/NebulaOS-KE/NebulaOS-firmware/wiki/Runtime-Helpers) |
| `docs/reference/TOOLING.md` | [Build scripts and host tools](https://github.com/NebulaOS-KE/NebulaOS-firmware/wiki/Build-Scripts-And-Host-Tools) |

The rest of `docs/` is unchanged: roughly 120 design and analysis documents, which remain the
place to read *why* things are the way they are. The wiki answers *what exists*, from source.

## Regenerating

Five of the wiki pages are generated by tools in the central NebulaOS repository and must not be
edited by hand. From a checkout of that repository:

```sh
python3 documentation/agent/tools/gen_firmware_api_reference.py      <fw> <fw>/wiki/Moonraker-API.md
python3 documentation/agent/tools/gen_firmware_osconfig_reference.py <fw> <fw>/wiki/OSConfig-Helpers.md
python3 documentation/agent/tools/gen_firmware_services_reference.py <fw> <fw>/wiki/Boot-Services.md
python3 documentation/agent/tools/gen_firmware_runtime_helpers.py    <fw> <fw>/wiki/Runtime-Helpers.md
python3 documentation/agent/tools/gen_firmware_tooling_reference.py  <fw> <fw>/wiki/Build-Scripts-And-Host-Tools.md
```

Regenerate whenever this repository's tip moves.
